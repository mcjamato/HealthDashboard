# Version 1.3.0 Release Notes

This release adds four production-oriented improvements:

1. Every dashboard graph can export its underlying data as CSV. The Plotly
   toolbar remains visible and its camera icon downloads a high-resolution PNG.
2. Customer Data now contains Data Import, with separate Customer Entries and
   Blood Work import destinations.
3. Blood Work is stored in a flexible lab-results table and can be entered,
   imported, viewed, charted, and exported.
4. Administrators and clients can change their own passwords. Administrators
   can also reset active account passwords.
5. Nutrition includes an optional food-photo analyzer. On Streamlit Community
   Cloud, configure OPENAI_API_KEY in App Settings -> Secrets.

Food-photo results are estimates only and should not be interpreted as exact
dietary or medical measurements.
