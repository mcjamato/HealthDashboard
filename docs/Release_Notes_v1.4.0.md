# Version 1.4.0 - Multi-Month Dashboard Filters

Dashboard date filtering now uses one checkbox per available month.

When a dashboard opens, the newest available month is checked automatically.
For example, if August 2026 is the newest month, the initial dashboard shows
only August 2026.

Users can check July 2026, June 2026, or other available months to compare
longer trends. KPI cards, graphs, CSV exports, PNG graph downloads, and recent
records reflect the selected months.

At least one month must remain selected.
